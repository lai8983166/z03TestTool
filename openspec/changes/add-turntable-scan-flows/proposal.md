## Why

左侧面板「最小搜索范围」「光轴预置范围」两个流程是仅剩的 TODO 占位项。两者都需驱动转台按固定点位序列逐点转动、逐点停留，人工操作繁琐且停留时长不准。自动化后可保证每个位置精确停 5 秒并同步录帧，形成可追溯的测试数据。

## What Changes

- 实现两个转台扫描流程，共用同一**偏移序列**（内环方位偏移, 外环俯仰偏移）共 8 点：
  (0,-45)、(-15,-40)、(22,-30)、(-23,-20)、(21,-10)、(-18,0)、(10,10)、(0,15)
- 第一次移动前查询转台当前位置，并沿用上位机服务已验证的基准换算规则（位置 >=140° 时减360°）；每个目标均为“流程初始位置 + 当前序列偏移”，不与上一个目标累加。光轴预置A帧写当前序列值本身，而不是转台绝对目标。
- **最小搜索范围**（最小跟踪视场测试）：勾选「允许截获」→ 开始数据采集 → 开始保存B帧 → 等待 5 秒 → 按点位序列转动转台（到位后每点停 5 秒）→ 最后一点停 5 秒后取消「允许截获」→ 更新A帧发出清除位 → 停止数据采集 → 停止保存B帧
- **光轴预置范围**：勾选「地面预置测试状态」→ 开始数据采集 → 开始保存B帧 → 等待 5 秒 → 按点位序列转动转台，每点到位后将「预置俯仰角/预置方位角」改为当前序列值并更新A帧发出 → 每点停 5 秒 → 最后一点后将预置方位角、预置俯仰角均置 0，取消「地面预置测试状态」并更新A帧发出 → 停止数据采集 → 停止保存B帧
  （注：用户未提"开始数据采集"，但预置指令随 A 帧发出、不发无效，故补上；取消动作同理需发清除帧——已与"最小搜索范围"收尾方式对齐）
- 转台到位判定：周期点击「状态查询」读取两轴速度与反馈位置，速度均为 0 且反馈位置与目标一致（±0.5° 容差）判到位，单点 60 秒超时判失败
- 新增工具函数：`setCellText`（设置发送帧可编辑单元格）、转台位置下发与到位轮询
- 流程正常结束、中止或异常时：停止转台（tt_btn_stop）+ 停止采集/A帧发送 + 停止保存
- 关闭主界面时中止当前流程、执行同样的页面清理并销毁隐藏窗口，确保 Electron 后台进程退出；不终止人工启动的上位机服务
- 前置条件（人工保证）：转台串口已连接、已进远控、已使能、内环/外环模式为位置模式

## Capabilities

### New Capabilities

- `turntable-scan-flows`: 转台扫描测试流程——公共点位序列与到位判定、最小搜索范围与光轴预置范围两个流程的动作序列、失败判定与过程输出

### Modified Capabilities

（无）

## Impact

- `flow.js`：两个流程实现 + `setCellText` 等小工具 + 转台扫描循环
- `main.js`：主窗口关闭与应用退出时的统一任务清理
- 无新依赖；不改上位机服务代码
- 运行前置：上位机服务运行、转台串口已连接/远控/使能/位置模式（人工）
