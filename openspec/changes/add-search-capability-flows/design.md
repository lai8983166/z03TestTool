## Context

Z03testTool 通过隐藏窗口驱动上位机页面，流程硬编码于 `flow.js` 的 `flows` 注册表，工具函数 `makeHelpers`（click/setInput[含复选框]/readCell/wait/readFile/waitForFile）。已探明的上位机服务事实：

- 「允许截获」= 复选框 `comboBox_HWJHKZ`（index.html:1645，置复合指令字 bit3）
- 「搜索指令」= 下拉框 `comboBox_SSZL`（index.html:1655-1663，A 帧构建读取于 Command.js:3957），选项值即文本：`001b九位波搜索`/`010b十六位波搜索`/`011b俯仰向三波位搜索`/`100b方位向三波位搜索`/`101b五波位搜索`/`110b四波位搜索`（另有 `000b不搜索`）
- 「开始数据采集」= `pushButton_SJCJ_F000H_Send`（Command.js:589-608，开始/停止切换）：启动后按 50ms 周期后台持续发送 A 帧，帧内容在启动瞬间从 UI 控件快照构建（Command.js:4076-4099）→ 勾选截获必须在启动之前
- 「开始保存A/B帧」= `pushButton_SJCJ_0010H`（Command.js:641-656，切换式）：每收到一个 B 帧，前端把 DOM 解码值拼成 CSV 行经 WS 发后端；停止时后端写 `./data/数据采集AB帧_<时间戳>.xlsx`（server.js:816-885），exceljs 双工作表「A帧」「B帧」，每行首列为 `new Date().toISOString()` 墙钟时间戳（Command.js:4349），数据列为已解码显示值（度）
- 光轴指向俯仰角/方位角 = B 帧表第 15/16 行（0 基 14/15），xlsx 中按表头文字「光轴指向俯仰角」「光轴指向方位角」定位列
- B 帧行率 ≈ 设备应答率（约 20Hz，15 秒约 300 行）；另有「应答帧号」列可作参考

## Goals / Non-Goals

**Goals:**
- `flows` 中实现六个搜索流程：公共采集序列 + 可配置的点检测参数 + 统一指标计算
- 读取 xlsx 的 B 帧工作表做离线分析，输出平均时间（ms）与范围（度）
- 异常/中止时可靠清理（停发送、停保存）

**Non-Goals:**
- 不解析原始 UDP 包（xlsx 已含解码值）；不做 A 帧内容分析
- 不做指标合格阈值判定（本 change 只输出指标，不判合格/超差）
- 不图形化展示波形

## Decisions

1. **六个流程共用一个参数化实现函数**：`runSearchFlow(h, config)`，config = `{名称, 搜索指令选项, 通道: '方位角'|'俯仰角', 连续帧数N, 区间[a,b], 下一帧严格大于阈值 或 round目标值 或 '正变负'}`；`flows` 里六个键各传各的 config。备选"六份复制粘贴"被否：判定规则同构，参数化反而更短且不出不一致错误。
2. **点检测算法（单遍扫描）**：遍历角度序列，维护区间内连续帧计数；九/十六波位达到 8 帧后要求紧邻下一帧 `v > 1`，其余非四波位达到 N 帧后要求紧邻下一帧 `Math.round(v) === target`，命中后清空窗口继续；四波位：`prev > 0 && cur < 0` 记点。点要求"连续"：条件帧必须紧邻连续区间，不允许跳过中间帧再匹配。
3. **读 xlsx 用 exceljs（新依赖）**：与上位机生成端同款库，API 稳定。文件定位：停止保存后轮询上位机服务数据目录 取 `数据采集AB帧_*.xlsx` 中修改时间晚于流程开始且最新的一个（waitForFile 模式）。表头行按文字找「光轴指向方位角/俯仰角」列与时间戳列（首列）。
4. **锚帧与时间**：锚帧 = 判定点的"下一帧"（近似N帧/负值帧）；时间戳为 ISO 字符串，`Date.parse` 转 ms 求差；平均时间 = (t21 − t1) / 5，保留 1 位小数输出 ms。
5. **每次录制前复位切换按钮状态**：按钮是切换式，若人工已启动采集，直接点击会反而停止，尤其会影响第一个执行的九波位流程。因此设置搜索指令后先按按钮文本停止遗留的保存/采集，再重新启动并验证按钮文本已进入“停止…”状态。
6. **清理用 try/finally**：录制无论正常结束、异常还是中止，finally 中执行：若保存开关处于开启则点击 `pushButton_SJCJ_0010H` 停止、若数据采集处于开启则点击 `pushButton_SJCJ_F000H_Send` 停止。停止依据：按钮文本（更新A帧后按钮变为"停止数据采集"）。
7. **录制进度日志**：录制 15 秒，每 1 秒输出剩余秒数；分析期输出总帧数、命中点序列进度（每点一行）。

## Risks / Trade-offs

- [xlsx 单元格角度精度/格式未知（显示值 toFixed 位数未确认）] → 解析 parseFloat，NaN 帧跳过并计数；实施时先跑一次真实保存文件人工核对列名与数值
- [15 秒内应答帧率不足导致 <21 点] → 按失败判定输出实际点数（用户已确认）；不自动延长录制
- [停止发送循环为 async while，点停止后可能多发一帧] → 无实质影响（多一帧 A 帧发送），finally 停止后不再依赖发送状态
- [保存文件由后端异步写盘，停止后立即读取可能未完成] → 停止后轮询等待文件 mtime 更新且大小稳定（复用 waitForFile 思路）再读
- [阈值边界与 round 边界受浮点影响] → 九/十六波位严格按 `> 1`（1.0 不命中）；其余流程按标准 Math.round 语义，不额外容差；联机验证时观察实际波形再议
